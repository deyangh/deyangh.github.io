Notable Projects

StressID: Multimodal Physiological Stress Detection Pipeline

Designed and built a three-branch multimodal pipeline (Audio, Face, Gesture) for real-time stress classification using the NeurIPS 2023 StressID dataset.

Key Contributions:

  • Custom End-to-End Audio Pipeline: Engineered a full preprocessing and modeling pipeline from raw audio — extracting 128-bin Mel Spectrograms at 16kHz with per-sample normalization and SpecAugment (frequency + time masking) for robust training.
  • CNN-Transformer Architecture: Built a custom 3-block CNN (Conv2d → BatchNorm → ReLU → MaxPool) feeding into a Transformer Encoder (2 layers, 4 attention heads) with sinusoidal positional encoding and a Learnable Attention Pooling layer, outperforming mean-pooling baselines.
  • Baseline Benchmarking: Compared against a frozen Wav2Vec2 (facebook/wav2vec2-base) baseline using HuggingFace Transformers, with an MLP classification head trained on top of extracted embeddings.
  • Robust Evaluation: Implemented subject-level Stratified 5-Fold Cross-Validation with class-weighted CrossEntropyLoss to address extreme class imbalance (71% stressed), reporting Macro F1, AUC-ROC, MCC, and Balanced Accuracy across folds.
PyTorch CNN-Transformer Wav2Vec2 Mel Spectrogram SpecAugment MediaPipe Late Fusion
